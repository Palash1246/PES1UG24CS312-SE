# Lab 3 - Component Modelling and Architecture

Scenario: Hostel Maintenance & Issue Ticketing System.

## Submission files

- `Lab3_Component_Diagram.pdf` - component diagram for submission.
- `Lab3_Component_Diagram.png` - image version of the diagram.
- `Lab3_Component_Diagram.svg` - scalable vector version for editing.
- `Lab3_Architecture_Justification.docx` - one-page written justification.
- `Lab3_Architecture_Justification.pdf` - matching PDF export.

The architecture selection is layered. The diagram models the resident and warden portal, identity and access, ticket workflow, assignment and SLA worker, ticket repository, notification adapter, and attachment store. Connectors identify interfaces and protocols.
